# Landing · jugadorestrella.com

Archivos de la landing de Jugador Estrella. Lo que está en la rama `main` es lo que se publica.

- `index.html`: página principal
- `partners.html`: página de partners
- `images/`, `gallery/`, `videos/`, `descargas/`: recursos
- `deploy.sh`: lo corre un cron en cPanel; trae cambios y los copia a `public_html` (sin borrar nada)

Regla: nada se sube a `main` sin aprobación de Francisco ("publica").
